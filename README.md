# Nivetha Dhoti's — Classic v2

Classic men-only visual redesign.

## Direction
- South Indian traditional men's dhoti / veshti brand
- Ivory, teak brown, antique gold palette
- Classic serif-led typography
- Retail + wholesale positioning
- Men-only collections
- Responsive desktop/mobile layout

## Current scope
This is the visual foundation/prototype. Product cards use placeholders until actual product photos are added.
Retail/wholesale account logic, database, admin and checkout are intentionally not implemented yet.

Open `index.html` to review the design.
